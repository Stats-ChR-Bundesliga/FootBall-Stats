# Football Stats Dashboard

Αυτόματη ιστοσελίδα με στατιστικά Champions League και Bundesliga.

- Τα δεδομένα ενημερώνονται αυτόματα κάθε μέρα (GitHub Actions).
- Η ιστοσελίδα φαίνεται στο: `https://<username>.github.io/<repo-name>/`

## Ρύθμιση
1. Πρόσθεσε το API key σου στα Settings > Secrets and variables > Actions,
   με όνομα `API_FOOTBALL_KEY`.
2. Ενεργοποίησε το GitHub Pages: Settings > Pages > Source: `main` branch,
   folder: `/docs`.
